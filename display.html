    • A propriedade CSS display define como um elemento HTML é renderizado e posicionado,
    controlando se ele se comporta como um bloco, linha ou contêiner.

    Display: Block

    Exibe um elemento como um elemento de bloco (como p ). Ele começa em uma nova linha e ocupa toda a largura.

    Display: Inline

    Exibe um elemento em linha (como span). Quaisquer propriedades de altura e largura não terão efeito.

    Display: Inline-Block

    Exibe um elemento como um contêiner de bloco em linha. O próprio elemento é formatado como um elemento em linha, mas você pode aplicar valores de altura e largura.

    Display: Flex

    Exibe um elemento como um contêiner flexível em nível de bloco.

    Display: Inline-Flex

    Exibe um elemento como um contêiner flexível embutido.

    Display: Grid

    Exibe um elemento como um contêiner de grade em nível de bloco.

    Display: Inline-Grid

    Exibe um elemento como um contêiner de grade embutido.

    Display: flow-Root

    Cria um contexto de formatação de bloco, transformando um elemento em uma caixa de layout independente.

    Display: Table

    Permita que o elemento se comporte como um elemento.

    Display: Block-Flow

    Cria uma caixa em nível de bloco que se empilha verticalmente, ocupando 100% da largura, enquanto instrui seus filhos a usar o layout normal de bloco e em linha (flow).

    Display: Block-Flex

    faz com que um elemento ocupe toda a largura disponível e quebre a linha, enquanto display: flex transforma um contêiner em flexível.

    Display: Block-Grid

    Você aplica “display: grid” a um elemento. Os filhos diretos desse contêiner se tornarão automaticamente itens da grade e poderão então ser organizados em colunas e linhas

    Display: Block Flow-Root

    Define explicitamente os tipos de exibição externa e interna de um elemento, criando um contêiner em nível de bloco com um novo contexto de formatação de bloco para seu conteúdo.

    Display: Inline Flow

    Refere-se à forma como os elementos em linha são exibidos horizontalmente, um após o outro, na direção em que as frases são escritas, de acordo com o modo de escrita do documento.

    Display: Inline Flex

    Cria um contêiner flexível que se integra ao conteúdo ao redor como um único elemento embutido.

    Display: Inline Grid

    Cria um contêiner em forma de grade que se adapta ao conteúdo ao redor como um elemento embutido.

    Display: Inline Flow-Root

    sintaxe explícita de múltiplas palavras-chave.
