Definição do Display:


A propriedade CSS display define como um elemento HTML é renderizado e posicionado, controlando se ele se comporta como um bloco, linha ou contêiner.

Display: Block

Exibe um elemento como um elemento de bloco (como p ). Ele começa em uma nova linha e ocupa toda a largura.

Display: Inline

Exibe um elemento em linha (como span). Quaisquer propriedades de altura e largura não terão efeito.

Display: Inline-Block

Exibe um elemento como um contêiner de bloco em linha. O próprio elemento é formatado como um elemento em linha, mas você pode aplicar valores de altura e largura.

Display: Flex

Exibe um elemento como um contêiner flexível em nível de bloco.

Display: Inline-Flex

Exibe um elemento como um contêiner flexível embutido.
