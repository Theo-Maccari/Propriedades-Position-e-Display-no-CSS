Propriedades de display

    • A propriedade CSS display define como um elemento HTML é renderizado e posicionado,
    controlando se ele se comporta como um bloco, linha ou contêiner.

    Display: Block

    Exibe um elemento como um elemento de bloco (como p ). Ele começa em uma nova linha e ocupa toda a largura.
